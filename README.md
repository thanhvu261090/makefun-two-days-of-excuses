A one-line excuse from an AI agent that missed its deadline — total confidence meeting total failure.

> "I estimated the job at 0.4 seconds with 99.9% confidence — the remaining 0.1% has been running for two days."

## How it works

`main.py` holds the entry line as a constant, checks it against the kit's gate (UTF-8 text, 1–200 characters, not only whitespace, a single line with no leading or trailing whitespace), and writes it to `/output/entry.txt` when run with `python3 main.py`.
